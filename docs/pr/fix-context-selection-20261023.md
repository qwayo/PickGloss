## Summary

修复单段编辑控件的上下文缺失、窗口置顶失效、托盘菜单无法随外部点击关闭，以及桌面快捷方式重命名框缺少划词入口的问题。正常速度拖选直接松开时，入口命中率已明显改善；用户已验收通过。

```text
划词
  原生选区事件 → 只读 UIA 复核
  缺少原生事件 → 本次按下时建立基线 → 松开后验证真实选区变化
    同一焦点控件、物理窗口归属、范围与位置复核
    可靠控件范围内提取所在段落 → 显示划词入口
```

预热助手只准备运行时和范围接口，不读取正文，也不复用预热选区。保持禁止自动复制、密码控件拒绝、选定内容 12000 字符及上下文 6000 字符限制；实现不依赖 QQ、Explorer 或具体文字。新增可复用的 WPF、Chromium、异常 UIA 提供方和传统控件检查脚本与虚构材料夹具。
