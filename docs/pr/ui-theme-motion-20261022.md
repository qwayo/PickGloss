## Summary

修复解释窗口连续唤回逐次变大、磨砂圆角与阅读视图底部背景问题，完善主题设置、会话入口和生成中的操作状态。

```text
PickGloss
├── 解释窗口：原生圆角、稳定展开／收回、独立记忆两档尺寸
├── 外观与设置：深浅主题、配色选择、置顶描边、紧凑窗口设置
├── 悬浮球：左键打开／关闭最新会话，可改为截图框选；右键菜单
├── 划词入口：跟随松开位置，主题配色、无阴影圆角与出现动效
└── 阅读与会话：上下文标记、输入对齐、生成结束后显示操作栏
    └── 会话历史筛选／改名、快捷键配置和草稿保护
```

## Evidence

- **Before:** 连续唤回 30 次，原生窗口从 302×485 增长到 332×515。
  **After:** 相同边界不再重复写入；当前位置与右下边缘各唤回 30 次，尺寸均保持不变。连续点击按顺序打开／关闭，草稿保存失败时保留窗口。
- **Before:** 阅读视图输入框左侧露出主窗口底色，分界线中断；划词入口底边截断阴影。
  **After:** 四种明暗／材质组合下，左侧背景和边线随多行输入保持连续；划词入口去掉阴影、同步加圆按钮与矢量底板，底边透明检查通过。
- **Before:** 生成提示重复，复制与重新解释在输出中提前出现。
  **After:** 等待首段时只显示一处呼吸圆点提示，首段出现后移除；当前回答生成结束后再显示操作栏。

## Merge Danger

**Door:** two-way

代码可回退，无破坏性会话迁移。回退前保留 `settings.json` 备份：旧主分支保存设置时会忽略新增偏好，中间版本的严格外观校验也可能不接受新增描边字段。

**Blast Radius:** 桌面端

涉及原生窗口边界、截图入口、划词入口、设置持久化与渲染状态；重点关注不同 Windows 版本和缩放比例下的圆角、窗口位置及焦点行为。
