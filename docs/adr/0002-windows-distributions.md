# Windows 安装版与便携版共用本机数据

PickGloss 从同一提交构建 Windows x64 按用户安装版和单 EXE 便携版。两版共用 `%LOCALAPPDATA%\PickGloss\data` 和现有单实例锁，方便用户从 ZIP 迁移或切换发行版时继续使用已有设置与历史。

两版共用同一个 Windows 登录项。登录项指向另一份 EXE 时，设置显示「使用当前版本开机启动」。用户确认后，登录项才切换到当前运行的入口。便携版登记用户直接打开的外层 EXE 路径。

首版提供更新检查。启动约 20 秒后检查一次，托盘驻留期间每 6 小时检查，退出后停止。用户可以在设置中关闭自动检查或手动检查。仅在公开 GitHub Release 存在较新的正式版本及对应发行物时，在托盘和设置提示新版，由用户打开发布页下载。

[ADR 0001](0001-gated-release-cd.md) 的发布门禁适用于新增的两个 EXE。发布流程将它们纳入同批候选包，验收与审批后公开冻结产物，并逐件回读核对。
