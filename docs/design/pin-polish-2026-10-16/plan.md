# 固定窗口反馈与阅读过渡精修

意图：按用户点名的视觉与音效改法精修现有状态，并继续修复正式 0.1.11 展开时的抖动；不重开品牌或整页方向选择。本文保留本轮设计决策，不依赖已归档的内部工单编号。

固定窗口要回答的是“这个窗口现在会留在阅读旁边吗”。用贴合原有 13 像素圆角的橙色 3 像素轮廓直接表明状态，外侧留出柔光空间，向外逐渐透明；不在内容区加宽边距，不缩小正文，不改变尺寸记忆。外光只绘制，不接收鼠标或焦点，也不接入会话与设置的 IPC。取消固定或隐藏窗口，实线与外光一起撤回。

按用户最后的反馈，轮廓改为较暗的橙色 `#dc873d`，外光采用 `218 116 39`，三层透明度为 0.52、0.27、0.11。主窗的原生底板保持透明，由界面内部绘制炭黑、暖白或磨砂表面，去掉圆角外的四个黑色尖角；主窗与外光共用圆角尺寸。

声音是一声快速的玻璃敲击，起音明确、亮而短，约 190 毫秒内自然衰减；提高实际播放电平，保留音效开关和事件去重。数字峰值和削波检查不代替用户的扬声器与听感。

历史搜索区去掉额外的实色底板，搜索框仅用细边界与焦点状态表达可输入性，沿用页面自身的实色或磨砂背景；标题、搜索、筛选、数量与列表一起自然滚动，避免透明搜索区盖住滚过来的会话。搜索范围、收藏和回收站规则不变。

缩放按实际绘制反馈环继续定位。已确认隐藏原生调用更频密仍不能消除两档布局在 640 像素处的硬切；需要分别处理布局与尺寸更新错帧、两档位移过渡，以及持续换行。保持正式 DOM、真实原生尺寸动画、阅读锚点、草稿和减少动态效果，不使用旧新截图交叉淡化。隐藏离屏绘制与 Windows 前台合成保持不同证据范围。

最终实现于尺寸事件当次同步布局，以 200 毫秒纯位移衔接原文、回答和追问区的跨栏变化。反向操作从当前呈现位置接续，避免先跳到旧终点。回答区在过渡期间使用同一页面底色并裁剪横向溢出，完成、取消、重绘、卸载及系统减少动态效果切换均清理临时状态。离屏检查保留原来的位移阈值，不把自动化通过表述为前台帧率或真人流畅度验收。
