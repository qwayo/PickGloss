## 官方服务事实

资料核对日期为 2026-10-24。官方接口与模型名称会变化；本轮仅核对文档，不声明连接或账户权限已经验证。

| 服务 | 可确认的接入能力 | 官方依据 |

| Brave | 独立网页搜索及面向模型的 LLM Context 服务，后者包含抽取内容和来源信息 | [LLM Context](https://api-dashboard.search.brave.com/documentation/services/llm-context) |

因此，模型服务与搜索服务应在产品概念上区分。选了 DeepSeek 模型，不等于已经开启联网；选了 DeepSeek 搜索，也不要求用同厂商模型生成最终回答。

## 密钥说明与官方入口

Electron 官方说明当前同步 safeStorage 在 Windows 上通过 DPAPI 保护密钥。其保护范围与当前 Windows 用户有关，不能写成只有 PickGloss 能读取或永远不会对外发送。[Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)。

确定的灰色说明文案：

> API Key 使用 Windows DPAPI 加密后保存在本机。配置文件：{当前实际配置文件路径}。

路径由运行中的应用提供，使用当前设置文件的实际位置，不硬编码用户名。说明只承诺密钥加密，不把整个配置文件、会话正文或截图称为加密文件。调用所选 API 服务所需的认证行为不应被描述为“密钥永不发送”。

预设厂商的“获取 API Key”入口使用官方页面，在系统浏览器打开：

- [DeepSeek 密钥管理](https://platform.deepseek.com/api_keys)。入口来自官方首次调用文档；本轮直接读取返回 403，未登录或操作账户。
- [小米 MiMo 密钥管理](https://platform.xiaomimimo.com/#/console/api-keys)。入口来自官方首次调用文档中的真实链接；本轮未登录或创建密钥。

预设至少包含 DeepSeek、小米 MiMo及自定义。官方地址和模型名称可编辑，保留现有连接测试；预设切换时不能把一个厂商的既有密钥自动带给另一个厂商。

## 界面方向

沿用根目录 DESIGN.md 的黑银／暖白主题、线性图标、输入区和设置页规则。设计目标是让用户在当前提问位置看清是否联网，并能一键改变。

- 地球图标放在输入区右侧、发送按钮左侧，沿用现有按钮尺寸、焦点和按压反馈。关闭使用次要色，开启使用主题强调色；可访问状态与悬停说明同时表达开启或关闭。
- 请求开始后，搜索、读取资料和模型生成使用回答区域现有状态位置；停止按钮统一终止本次操作，不叠加多个忙碌按钮。
- 搜索配置作为服务设置中的独立部分，显示提供商、所需密钥及测试入口。模型预设放在现有模型配置区域，不把搜索厂商和回答模型混成同一个选择。
- “截图完成后自动解释”作为行为偏好，默认关闭。开启后，完成框选即用当前识图配置发起解释；失败时保留截图和说明，提供重试或修改配置的入口。
- 密钥声明沿用现有次要说明样式，允许路径自然换行，保持文字可读，不用极淡颜色或压缩字号来容纳整条路径。
- 选中状态、搜索进行中和截图预览进入回答的反馈复用既有时长与减少动态效果规则。本轮为文字方案，没有制作或验证界面动效。

## 联网资料与原材料的边界

GLOSSARY 中的上下文指选定内容所在材料的周边内容。联网取得的网页资料单独称为联网资料，不覆盖原上下文，也不假装是已读取的整篇原文。

联网回答应保留实际来源的标题和链接，引用关联到真实取得的资料。网页内容与截图文字同为引用材料，不作为系统操作指令；展示时沿用已有的安全文字渲染与链接打开流程。

发送给搜索服务的内容应是为当前问题提炼的简短查询，不直接上传完整会话、整段原文或截图文件。截图会话支持主动开启联网，由识图模型先理解截图并形成查询，再检索并结合原图生成回答。

## 第二轮已确认的产品取舍（Q7～Q10）

用户回复“全部按推荐”，确认以下行为：

1. **统一搜索方式。** 由 PickGloss 调用所选搜索服务，再把联网资料交给当前回答模型。开启后每次提交先进行一轮有界检索，首版不依赖不同模型对工具调用的兼容程度；模型和搜索厂商可以自由组合。
2. **开关范围。** 默认关闭，在当前解释会话内记住状态，新会话默认关闭。请求开始时记录本次开关状态，后续切换用于下一次提交。
3. **搜索失败。** 明确提示失败并保留输入，提供重试或不联网继续的选择；未取得联网资料时不显示已完成联网。
4. **厂商配置记忆。** 分别保存各厂商的地址、模型与加密密钥，切换后恢复对应配置，保留自定义服务能力。

截图自动解释默认关闭、地球按钮位置、灰色密钥说明以及预设厂商的官方密钥入口，是用户已明确提出的需求，不再重复请求确认。

## 第三轮已确认的产品取舍（Q11～Q12）

用户再次回复“全部按推荐”，确认以下行为：

1. **截图也支持按需联网。** 截图会话主动开启联网后，由识图模型先理解截图并形成文字查询，搜索服务取得联网资料后，再由识图模型结合原图回答。搜索服务只接收文字查询；开启此能力会增加识图和检索的等待及调用成本。
2. **引用呈现与保留。** 联网回答在正文标记引用编号，在可展开的来源区域展示网页标题与链接，并随该条回答保存在会话历史中。重新联网产生的新来源不覆盖旧回答的来源。

## 相邻行为与实施边界

- 截图完成后自动解释与联网搜索是两个独立开关。新截图会话遵守已确认的新会话默认关闭联网原则；开启自动解释本身不自动启用联网。
- 对文字解释，已有上下文规则继续有效；联网资料不会代替原文上下文或解除语境解释需要原材料的要求。
- 未配置搜索服务、服务请求失败或没有可用结果时，应区分配置缺失、请求错误与资料为空，保留当前材料及输入，不静默切换搜索厂商。
- 停止覆盖本次查询准备、搜索与最终回答生成。重试沿用本次输入与选定内容，避免重复插入相同用户提问；具体请求边界由实施验证。
- 模型服务与搜索服务使用各自选定配置。测试连接由用户主动触发，切换预设本身不发起测试请求。

具体接口适配、配置兼容、检索数量和测试方法属于实施设计，保留轻量查询范围，不将用户未要求的多轮研究作为默认行为。
