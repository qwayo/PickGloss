# 领域文档

本项目采用单上下文布局：

- 根目录 `GLOSSARY.md`：领域术语。
- `docs/adr/`：架构决策记录。

## 阅读规则

探索代码前，读取已存在的 `GLOSSARY.md`，并读取与当前工作相关的 ADR。

若以后出现根目录 `GLOSSARY-MAP.md`，先读取该索引，再读取与当前主题相关的上下文术语表和 ADR。

相关文件尚不存在时，直接继续工作。领域术语或决策明确后，由 `domain-modeling` 按需创建文档。

## 术语与决策

任务标题、设计方案、假设和测试名称中的领域概念，使用术语表定义的名称。

遇到未收录的概念时，先确认是否已有对应术语；确有缺口时，记录为后续领域建模事项。

方案与现有 ADR 冲突时，明确指出 ADR 编号、冲突内容及重新讨论的理由。
